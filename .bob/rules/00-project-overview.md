# Project Overview — AI Design Infrastructure (Bob harness)

This repository runs a structured four-tier design process (Discovery → Definition → Design → Develop) with two cross-cutting knowledge modes (Lint + Query). The process is implemented by 32 skills living under `.bob/skills/`, each corresponding to a design mode or a Figma sub-skill.

## Single source of truth

`design/process/` — 20 numbered markdown chapters (`00-overview.md` through `20-query.md`) plus `README.md`. Chapters describe each mode's mental model, workflow, outputs, and rules. Skills are derived from chapters; chapters are authoritative.

## How changes work

- Designers never edit `design/process/` directly. They describe the change; the `workflow-update` skill edits the chapter and propagates to every affected file.
- Propagation targets are defined in `design/process/_propagation.yaml` — shared between the Claude and Bob harnesses.
- Mirror parity is enforced by `node design/scripts/sync-skills.js`.

## Operational model — Ingest / Query / Lint

A cross-cutting lens. Tier tells you *when* a skill runs; operation tells you *what kind of work* it does.

- **INGEST** — produce authoritative artifacts from raw inputs or upstream artifacts.
- **QUERY** — aggregate the corpus into a retrieval surface (canvas briefs per screen, WIKI per entity).
- **LINT** — cross-check for drift, gaps, and principle violations.

## Non-negotiable rules (summary)

1. Journeys and stories are tech- and UI-agnostic.
2. Canvas briefs are the single source of truth for build intent.
3. Every design decision traces back to a persona, a story, or a principle.
4. No Figma screen without a canvas brief.
5. No prototype screen without a Figma implementation.
6. Zero hardcoded values in Figma — every token referenced.
7. Accessibility is built in (WCAG AA minimum).
8. The Develop loop stays in sync; drift is detected and resolved.
9. Staleness is visible; artifact versions are tracked.
10. Retire, don't delete — IDs are stable, lineage is preserved.

## Key commands

- `node design/scripts/sync-status.js` — pipeline staleness sweep
- `node design/scripts/sync-traceability.js` — bidirectional traceability check
- `node design/scripts/sync-composition.js` — composition-log ↔ brief ↔ inventory check
- `node design/scripts/sync-skills.js` — harness mirror-parity check (both `.claude/` and `.bob/`)
- `python design/scripts/sync-brd.py` — regenerate `design/BRD.xlsx` from md SSOT files
- `node design/scripts/migrate.js` — post-merge migration-status check
