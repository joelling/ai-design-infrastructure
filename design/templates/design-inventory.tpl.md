# Design System Inventory

> Managed by `figma-inventory`. Do not edit manually — use the inventory skill to add, update, or retire entries.

## Status values

| Status | Meaning |
|---|---|
| `draft` | In progress on a working page — not ready for use |
| `staged` | In Parking Lot — ready for review before library promotion |
| `published` | In the library — available for use across all files |
| `deprecated` | Still available but scheduled for removal — migrate away |
| `removed` | No longer in the library — archived entry only |

### Schema

| Field | Values |
|---|---|
| Name | `Category/ComponentName` — follows naming authority from contribution-guide.md |
| Type | `component` / `token-collection` / `style` / `icon` / `illustration` |
| Status | `draft` / `staged` / `published` / `deprecated` / `removed` |
| Location | Figma file name + page name |
| Taxonomy | Primary category (Form, Navigation, Feedback, Data, Layout, etc.) |
| Last updated | YYYY-MM-DD |
| Notes | Migration path (if deprecated), replacement (if removed), open issues |
